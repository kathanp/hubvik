# @hubvik/cli

@hubvik/cli 0.1.4. UNVERIFIED.

Commands: `replay`, `report`, `doctor`, `rules check`, `baseline`, `coverage`, and `selftest`. `replay` loads `hubvik` when it is installed. Tests inject `createEngine`. `doctor` keeps the tier and clock report and adds `plan` when the engine provides it. The HTML report is self-contained and has no network requests.
