D-25 | WP-14 | bounded reorder does not sort events | `reorderMs` accepts a late event and does not delay one that already arrived. `src-spoof` uses the lease it has seen. `packet-flood` reports the running total when the threshold is crossed. `proxy-relay` timestamps the event that completes the set and lists families in arrival order. `supply-chain-suspect` names whichever of those fires first. The relation still requires every other anomaly to match. Superseded by D-26
D-26 | WP-14.1 | a reorder buffer delivers events in timestamp order | `reorderMs > 0` holds accepted events until `ts <= watermark - reorderMs`, and `flush` / `tick` release up to their limit. `reorderMs: 0` does not create a buffer. `src-spoof` was a critical false positive when a flow arrived before the DHCP ack that updated the lease
D-27 | WP-15 | golden.md fired seven detectors, so there is no top 20 | Hits: horizontal-scan 7, new-beacon 6, packet-flood 6, protocol-mix-shift 6, new-protocol 1, beacon-change 1. Evasion: egress-flood 1. Those seven, every hard rule, and the three shadow detectors set `meta.explains`. `spec-coverage` prints `explains: X of Y detectors` and does not fail on a low count
D-28 | WP-18.1 | `test/diff` ignores `baseline.engine.pkg` | The 0.7.0 bump had to edit `test/diff/golden.json` only because the baseline records the package version. `windowMs` is still compared. The owner asked for this as D-27; that id was already the WP-15 golden-hits note
D-29 | WP-18.1 | core unpacked cap is 750 KB, with a 60 KB file rule and a 200 KB `src/data` rule | Raised from 500 KB on 2026-10-18. OpenWrt-class hosts that run Node have far more flash, and Node itself is > 30 MB. `src/engine/engine.js` was already 65,951 bytes, so it is reported and not split. Any other file over 60 KB fails pack-check. The owner asked for this as D-28; that id is the package-version decision above
D-30 | WP-19 | `multi-horizon-exfil` uses `h = 1` byte when learned hourly σ is 0 | Page CUSUM rejects a decision limit of 0, and `8 × 0` is 0. One byte is the smallest positive limit `stats/cusum.js` accepts. `k` stays 0
D-31 | WP-20 | `graph-role-change` skips `hub`, `nas`, and `smart-tv`; `lan-via-proxy` is stage impact | The 0.8 prompt names `smart-tv`, and the Kimwolf campaign needs an impact stage. `lan-via-proxy` is that stage. B21 had listed `hub` twice and omitted `smart-tv`
D-32 | WP-21 | a `learn()` return with `severity` and no `reason` is emitted | `nd-spoof` is shadow (`hardRule: false`) and a router-address claim still has to fire during learning. `check()` does not run then. The return is a shadow anomaly. A `{ reason }` return is still `SUSPICIOUS_LEARNING` only
D-33 | WP-21 | `peer-divergence-federated` is Rel 0.9 | It stays unimplemented until WP-25. A Rel 0.8 row with no file would fail spec-coverage at package 0.8.0
D-34 | WP-21.5 | `shadow` defaults to false | Supersedes the enabled-by-default part of D-19. Shadow detectors never alert a user. Only a pilot reads them, so a default engine does not pay memory or CPU for them. `shadow: true` or a listed id runs them. `detectors[id].enabled` still wins. The owner labeled this D-29; that id is the WP-18.1 pack-cap decision
